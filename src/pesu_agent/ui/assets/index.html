외부 AI 분석 허용

질문에 답하기 위해 검색된 Slack 메시지 일부와
입력한 질문이 설정된 AI 모델 제공자에게 전송될 수 있습니다.

• 이 허용은 PESU를 종료할 때까지 유지됩니다.
• Slack 메시지를 작성하거나 전송하는 권한은 포함되지 않습니다.

OpenRouter API 키 설정

PESU의 AI 분석 기능을 사용하려면 OpenRouter API 키를 설정해 주세요.
입력하신 키는 이 Windows 사용자 계정에 암호화되어 안전하게 저장됩니다.

• 저장된 키는 평문으로 노출되거나 디스크에 남지 않습니다.
• 언제든지 키를 다시 변경하거나 제거할 수 있습니다.

PESU에 오신 것을 환영합니다

PESU는 필요한 업무 정보를 찾아 근거와 함께 정리해 주는 개인 AI 도우미입니다.

• 현재 Slack 연결은 읽기 전용입니다. PESU가 Slack 메시지를 작성하거나 전송하지 않습니다.
• 데이터는 안전하게 보호되며 사용자의 질문에 의해서만 검색됩니다.

AI 모델 연결 (OpenRouter)

✓
OpenRouter 설정됨

AI 모델이 연결되어 바로 조사를 진행할 수 있습니다.

PESU의 분석 기능을 사용하려면 OpenRouter API 키가 필요합니다.

• Slack 내용을 외부 AI로 분석해야 할 때는 실행 중 별도로 허용을 요청합니다.
• API 키는 Windows DPAPI로 안전하게 암호화 보관됩니다.

Slack 연결 안내

PESU는 전용 Slack 세션을 통해 필요한 대화를 읽기 전용으로 검색합니다.
이미 로그인되어 있다면 별도 설정 없이 다음 조사에서 사용할 수 있습니다.

필요한 경우:

• 처음 질문 시 Slack 로그인이 필요하면 자동으로 다시 안내됩니다.
• 설정 메뉴에서 언제든지 상태를 확인하고 변경할 수 있습니다.
